# Integrations

<!-- GA-GENERATED:index -->

- [Clerk](clerk.md) - Clerk handles sign-up, sign-in and sessions; its webhook keeps the User table in step with Clerk.
- [Google AdSense](google-adsense.md) - The AdSense script is loaded on every page in production when a publisher id is set.
- [OneSignal](onesignal.md) - Web push notifications: the browser registers with OneSignal under the user's id, and the server sends pushes through OneSignal's REST API.
- [UploadThing](uploadthing.md) - An image-upload route for signed-in users, up to 4MB per image, with React helpers in components/uploadthing.
- [Vercel Analytics and Speed Insights](vercel-analytics.md) - Page analytics and performance metrics from Vercel, loaded in production only.
